# 遇见桂信科 · 桂林信息科技学院校园风采展示网站

> 「AI创想桂信科」AI应用创意赛道 · AI网站与轻应用创意赛 参赛作品
>
> 🌐 **在线访问：https://liangwenjing-abc.github.io/guiling/**（已部署 GitHub Pages）

一个以 **桂林信息科技学院** 为对象的校园介绍网站：把学校官网上的概况、专业、成果、照片、联系方式等真实信息，重新组织成一个更好逛、更好看的多页面网站，并提供**可拖动的互动校园路线图**、相册灯箱、专业筛选、新生小测试等互动体验。

---

## 一、如何查看

**双击 `index.html` 即可**。无需安装、无需联网、无需服务器（纯静态网站，全部资源在本地）。

- 推荐浏览器：Edge / Chrome（Windows 自带 Edge 即可）
- 手机上看：把整个文件夹拷到手机或访问上面在线地址即可（已做响应式适配）

## 二、页面结构

| 页面 | 内容 |
| --- | --- |
| `index.html` 首页 | 校门大图主视觉、数据速览、八大专业集群、院系与专业、办学成果、校园相册预览、**校园路线推广区**、校园新闻、**新生小测试（互动）** |
| `about.html` 走进信科 | 学校简介全文、校训与办学理念、历史沿革时间轴、办学条件数据、人才培养模式 |
| `majors.html` 院系与专业 | 7 个学院、41 个普本专业总表（**按学院筛选**）、专业与课程建设成果 |
| `honors.html` 办学成果 | 学科竞赛、就业质量（含专业就业案例）、产教融合、荣誉榜单与媒体报道 |
| `campus.html` 校园相册 | **25 张校园照片**（分类筛选 + 灯箱大图）、校园生活设施 |
| `route.html` 校园路线 | **可拖动 / 缩放的插画互动地图**：13 个点位详情、3 条主题路线一键切换、地图自动飞行定位、站点面板（照片＋简介） |
| `contact.html` 联系我们 | 校址、招生热线、学校邮箱、校长信箱、官方平台入口与官方微信二维码 |

## 三、技术说明

- **纯 HTML + CSS + 原生 JavaScript**，零依赖、零构建，可完全离线运行
- **互动校园路线图**：基于 Pointer Events 实现地图拖动 / 滚轮与双指缩放；三条路线切换时地图自动“飞行”到路线区域；SVG 路线虚线动画与站点编号高亮；点击站点查看详情、上一站/下一站翻页
- 响应式布局（桌面 / 平板 / 手机三档断点）
- 其他交互：滚动进度条、滚动出现动画、数字滚动、相册分类筛选与灯箱（支持键盘）、专业表筛选、新生小测试、移动端导航、返回顶部
- 视觉细节：主视觉慢速推近、印章与页脚水印、数据条水印、图片渐显、卡片与按钮微交互
- 图标为内联 SVG / 文字符号，不依赖任何图标库；字体使用系统字体，不依赖网络字体

## 五、素材与数据来源

- **文字与数据**：桂林信息科技学院官网（www.guit.edu.cn）「学校简介」「专业设置」「新闻」等栏目及招生网公开信息，数据统计至 2026 年 6 月
