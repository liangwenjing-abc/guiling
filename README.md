# 遇见桂信科 · 桂林信息科技学院校园风采展示网站

> 「AI创想桂信科」AI应用创意赛道 · AI网站与轻应用创意赛 参赛作品
>
> 🌐 **在线访问：https://liangwenjing-abc.github.io/guiling/**（已部署 GitHub Pages）

一个以 **桂林信息科技学院** 为对象的校园介绍网站：把学校官网上的概况、专业、成果、照片、联系方式等真实信息，重新组织成一个更好逛、更好看的多页面网站，并提供**可拖动的互动校园路线图**、相册灯箱、专业筛选、新生小测试等互动体验；全站右下角还有一个 **AI 语音小助手「小信」**——会说话的橡皮人，点开就能和大模型对话问学校的事，还能带你逐块逛网站。

## 一、如何查看

**双击 `index.html` 即可**。无需安装、无需联网、无需服务器（纯静态网站，全部资源在本地）。

- 推荐浏览器：Edge / Chrome（Windows 自带 Edge 即可）
- 手机上看：把整个文件夹拷到手机或访问上面在线地址即可（已做响应式适配）

## 三、技术说明

- **纯 HTML + CSS + 原生 JavaScript**，零依赖、零构建，可完全离线运行
- **互动校园路线图**：基于 Pointer Events 实现地图拖动 / 滚轮与双指缩放；三条路线切换时地图自动“飞行”到路线区域；SVG 路线虚线动画与站点编号高亮；点击站点查看详情、上一站/下一站翻页
- 响应式布局（桌面 / 平板 / 手机三档断点）
- 其他交互：滚动进度条、滚动出现动画、数字滚动、相册分类筛选与灯箱（支持键盘）、专业表筛选、移动端导航、返回顶部
- 视觉细节：主视觉慢速推近、印章与页脚水印、数据条水印、图片渐显、卡片与按钮微交互
- 图标为内联 SVG / 文字符号，不依赖任何图标库；字体使用系统字体，不依赖网络字体
- **八大专业集群（首页重设计）**：从「8 张同构卡片」改成「左说明 + 右清单」——左栏是标题、导读、四个关键数字（8 大集群 / 7 个二级学院 / 43 个本科专业 / 7 大学科门类）和入口按钮，背景是双色调机械臂照片（暖调处理，非纯白非纯黑）；右栏 8 行清单，每行 `编号 + 图标 + 集群名 + 一句话 + 专业胶囊 + 对应学院`，全部内容一屏可见、不用点击。文件：`assets/css/clusters.css`（浅色主题 `.theme-l`；把 section 的 class 换成 `theme-d` 即为暗色照片版）
- **数据看板**（`honors.html`）：手写 SVG 四块图——就业落实率折线（84.1%→87.9%→88.59%）、师资双环（84.68% / 24.48%）、各学院专业数条形、办学规模；进入视区才生长，`prefers-reduced-motion` 直接给终值。首页只放一张就业率小火花线，细节留给成果页
- **校园服务页**：A/B/C 三 Tab（`services-page.js` 切换 + 吸顶二级导航）；办事数据在 `services.js` 顶部 `SVC` 数组里，材料支持「没有？」与「我缺材料」两种辅助；报修看板 `repair.js` 用 localStorage 存单、状态可点击推进，图片经 `xaVision` 调视觉模型自动生成描述与标签
- **AI 语音小助手**：`assets/js/assistant.js`（原生 JS，无依赖）+ `assets/css/assistant.css`。小人用 Pointer Events 实现"橡皮筋"拖拽与回弹，滑动窗口按当前板块讲解并高亮定位；对话走 DeepSeek 开放平台 `deepseek-flash` 模型的流式接口（SSE 逐字返回），支持语音朗读（Web Speech API）与语音输入（SpeechRecognition）、快捷提问、断网时本地知识兜底

## 六、AI 小助手「小信」说明

- **入口**：每个页面右下角——圆形按钮（里面是他的脑袋）+ 站在旁边的小人（形象由 AI 生成三视图后抠图得到，`assets/img/assistant/`）
- **趣味互动**：按住小人可以拖走（橡皮筋阻尼 + 身体倾斜拉伸），他会一路喊「你快放开我！」「帽子要掉了啦！」，松手后弹回原位；单击他会讲解你正在看的这块板块
- **动画**：随机眨眼（含连眨两下）、呼吸摇摆、随机小动作（点头 / 踮脚 / 左右张望 / 跳一下）、鼠标靠近时侧身看你、说话时点头、拖拽时拉伸、松手回弹、打开对话框时鞠躬、讲解时抬手、出入场动画
- **讲解网站**：点「带我逛一圈」，他会依次滚动到各板块、用红色虚线圈出位置并配一句解说，点小人继续下一站
- **对话**：点圆钮打开对话框，接 DeepSeek 大模型（`deepseek-flash`，流式输出），知识库含学校概况、学院专业、办学成果、相册、路线、联系方式等；回答里会给「带我去看」按钮，一键跳到对应页面或高亮对应板块
- **语音**：朗读默认打开（点对话框头部 🔊 可关闭），🎤 可用麦克风提问（需 Chrome / Edge）
- **配置**：密钥与模型名在 `assets/js/assistant.js` 顶部 `CFG` 中修改；接口不可用时会自动退回本地知识速答
- **安全提示**：纯静态站点把密钥放在前端是"会暴露"的，仅适合比赛演示；正式对外上线建议改成自建代理转发
